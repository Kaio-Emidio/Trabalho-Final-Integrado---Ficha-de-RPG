# Trabalho-Final-Integrado---Ficha-de-RPG

# Sobre o que é o site?

O sistema é utilizado principalmente de forma simultânea às sessões de jogo de RPG (que podem ocorrer presencialmente ou via internet, como no Discord). 
A frequência de uso será alta durante as partidas, para consultas rápidas e atualização de status (como perda de vida ou gasto de itens). 
Também será utilizado entre as sessões para a evolução (level up) e modificação contínua da história dos personagens. Ele substituirá integralmente o atual processo manual e desorganizado feito em blocos de notas de texto simples.
